# Solana SPL Token and NFT Playground

This project is a collection of TypeScript scripts to demonstrate the creation and management of SPL (Solana Program Library) tokens and NFTs on the Solana blockchain.

## Overview

The scripts cover the following functionalities:
1.  **Initializing a new SPL Token**: Creating a new token mint.
2.  **Adding Metadata**: Attaching metadata to the token, which can be used to represent it as an NFT.
3.  **Creating an Associated Token Account (ATA)**: Preparing an account for a user to hold the tokens.

## Scripts

### 1. `src/spl/spl_init.ts` - Initialize SPL Token

This script creates a new SPL token mint. A "mint" is the central authority for a token and defines its properties.

**Functionality:**
- Creates a new keypair for the mint account.
- Calculates the required rent-exempt balance for the mint account.
- Creates two instructions:
    1.  `CreateAccount`: To create the account for the mint.
    2.  `InitializeMint`: To initialize the account as a token mint with specific properties like the number of decimals and the mint authority.
- Sends and confirms the transaction.
- Logs the mint address and the transaction signature.

### 2. `src/spl/spl_metadata.ts` - Add Token Metadata (NFT)

This script adds metadata to the SPL token created in `spl_init.ts`. This is a key step in turning a fungible SPL token into a non-fungible token (NFT) or a token with rich details. It uses the Metaplex Token Metadata Program.

**Functionality:**
- Uses the Umi library from Metaplex for easier interaction.
- Defines the metadata for the token, including:
    - `name`: The name of the token (e.g., "Rai coin").
    - `symbol`: The symbol of the token (e.g., "CAT").
    - `uri`: A URI pointing to a JSON file with more metadata (e.g., image, description). This is empty in the script but is crucial for NFTs.
- Creates a `CreateMetadataAccountV3` transaction.
- Sends and confirms the transaction.

### 3. `src/spl/spl_mint.ts` - Create Associated Token Account (ATA)

This script doesn't actually mint new tokens. Instead, it prepares for minting by creating an Associated Token Account (ATA) for a specific wallet address. An ATA is the standard way for a user to hold a specific type of SPL token.

**Functionality:**
- Finds the Program Derived Address (PDA) for the Associated Token Account for a given mint and owner.
- Creates the `CreateAssociatedTokenAccount` instruction.
- The script is incomplete and does not send the transaction to create the ATA.

### 4. `src/spl/spl_transfer.ts` - (Empty)

This script is intended to handle the transfer of SPL tokens from one account to another, but it is currently empty.

## How to Run

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Update Wallet and Mint Address**:
    - Ensure you have a `devnet-wallet.json` file with your devnet keypair.
    - Update the `mint` address in `src/spl/spl_metadata.ts` and `src/spl/spl_mint.ts` to the address generated by `spl_init.ts`.

3.  **Run the scripts**:
    You can run each script using `ts-node`:
    ```bash
    npx ts-node src/spl/spl_init.ts
    npx ts-node src/spl/spl_metadata.ts
    npx ts-node src/spl/spl_mint.ts
    ```
